## Learning Objectives

1. **Use** `const` and `let` with numbers, strings, and booleans.
2. **Calculate** with arithmetic operators and compare simple values.
3. **Write** and call a function that returns a value.
4. **Use** `if`/`else` to handle a special case.
5. **Connect** a form event to a function and show the result as text.

**Estimated Time:** 45–60 minutes

# Module 04: JavaScript Essentials

Digital Proficiency Kit
Web Development for STEAM

---

## Purpose & Placement

- Builds on: Module 03 — CSS Styling & Layout
- Leads to: Module 05 — Data Visualization
- Core lesson sequence: 90–120 min across both units. Allow 3–4 hours if completing all tutorial and workbook practice in class.

**Key Artefacts:**

- Unit 4.1: a small calculator using functions, conditions, and a form event
- Unit 4.2: a list interface that updates from state

---

## Learning Outcomes

- Use variables, values, operators, functions, and conditions to solve a small problem
- Connect a form event to a calculation function
- Manage simple list state and render the interface from that state
- Apply accessible interactions and progressive enhancement

---

## Teacher Focus Points

- Unit 4.1: 45–60 min
- Unit 4.2: 45–75 min
- Projects: 30–45 min
- Common misconceptions: DOM vs. HTML; state vs. presentation
- Accessibility: Keyboard operability, focus management

---

## Big Ideas

- JavaScript adds interactivity
- DOM is the live document structure
- State drives UI rendering

Diagram:

```
User Event → JS Updates State → Render to DOM
```

---

## Vocabulary

| Term           | Example                  |
| -------------- | ------------------------ |
| DOM            | Document Object Model    |
| Event listener | `addEventListener`       |
| querySelector  | `document.querySelector` |
| State          | Data stored in variables |
| Function       | `function name() { }`    |

Glossary: See module README

## Demonstration

Unit 4.1: predict a calculation, write a function, then connect it to a labeled form.

## Guided Practice

## Independent Project

Build a dynamic UI component (to-do list, toggle, etc.) using state and rendering (see workbook for requirements)

## Assessment Criteria

- Functionality (interaction works)
- State management
- Accessibility (keyboard operable)
- Progressive enhancement
- Reflection

See Teacher Toolkit for full rubric

## Accessibility

- Use semantic buttons
- Ensure keyboard operability
- Provide visible feedback
- Manage focus when adding/removing elements

---

## Extension

- Add filtering or search
- Implement localStorage persistence
- Create multi-step forms with validation
